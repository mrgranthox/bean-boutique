## ⚡ Quick Start (10 minutes)

### 1️⃣ Run Database Setup (5 min)
Open **Supabase Dashboard** → **SQL Editor**:
- Copy & paste **`MIGRATION.sql`** → Click **Run** ✅
- Copy & paste **`SEED_DATA.sql`** → Click **Run** ✅

### 2️⃣ Deploy Backend (2 min)
```bash
supabase functions deploy make-server-4d0792a7
```

### 3️⃣ Make Yourself Admin (2 min)
In **Supabase SQL Editor**, replace email and run:
```sql
UPDATE public.users SET role = 'admin' 
WHERE email = 'your@email.com';
```

### 4️⃣ Launch! 🎉
- Open your app
- Sign in with your email
- Access **Admin Dashboard**
